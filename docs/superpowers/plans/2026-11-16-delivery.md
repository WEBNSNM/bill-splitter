# 配送单实施计划

已确认方案：首页分账单分类、配送单生成两个入口。配送单每校一个文件，每日期及分类对象一个 sheet；多订单编号全部列出。源文件、参考样例只读。

1. tests/test_delivery.py：先验证分组、金额逐步四舍五入、重新编号、样式、源文件不变、异常数据拒绝。
2. bill_splitter/delivery.py：独立读取销售明细，使用 Decimal 计算，按样例内置表头表尾，隐藏 A–E，独立目录输出及 JSON 报告，失败清理本次目录。
3. app.py：首页导航、配送模式说明、后台生成及运行状态互斥，保留账单模式。
4. 运行全部 unittest、源码编译、Tk 页面构建检查及真实数据只读导出校验；更新 README、CHANGELOG、HANDOFF，注明未进行 Excel 打印人工验收及未打包发布。

分类对象以源列为准，教师/老师标准化为教师，学生、活动单各自成单；空白、未知或冲突拒绝整次生成并显示源行号，避免漏单。明细保持源顺序，各 sheet 独立编号。折扣固定 0.957，单价及金额各自四舍五入到分。客户、公司抬头及签收说明采用参考样例内容。

# 需求与设计记录 · 2026-11-02

用户要求在 D:\project\prictice 创建独立项目，便于后续 Codex 优化，提供安装及使用说明。

输入：每月源账单第一个工作表，按客户名拆成学校文件。每校严格四张表，顺序为全部明细、总计表、老师明细、学生明细。
总计表四列：配送日期、老师、学生、总计；按日期汇总金额，底部合计。
老师类：收货地址包含教师、成人、职工、老师任一词。
学生类：收货地址包含幼儿、学生任一词。
两类同时命中或均未命中不自动归类。每校全部明细保留这些记录，分类页和分类总计排除，另出待核对清单。
默认销售金额(元)，用户可选下单金额(元)。所有金额按行 Decimal 四舍五入到分。

设计：Python 标准 Tkinter 本地界面 + openpyxl 文件操作；无云服务、无数据库。读取、验证、分类后写入独立目录；出错删除本次不完整目录。输出运行报告支持源金额=已分类金额+待核对金额核验。

原始账单包含“教师”备注，不能只匹配“老师”。此前会话发现 13 个有效客户名，但此项目不把数量写死。

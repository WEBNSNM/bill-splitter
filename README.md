# 学校账单分类工具

Windows 本地 Python 桌面程序。选择源账单的第一个 sheet，按“客户名”生成每校一个 Excel，每个文件包含：全部明细、总计表、老师明细、学生明细。

## 环境与安装

- Windows 10/11；Python 3.11 或以上（python.org 标准安装版，包含 Tkinter，安装时勾选 Add Python to PATH）。当前已使用 Python 3.14.6 创建 `.venv` 并安装依赖。
- 仅依赖 openpyxl 3.1.5；首次安装需要网络。运行无需网络，也无需安装 Excel；查看和重算公式建议使用 Excel/WPS。
- 新电脑：安装 Python，然后双击 `install.bat`。不要把旧电脑的 `.venv` 直接复制使用。

命令行安装：
```powershell
cd D:\project\prictice\bill-splitter
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

## 使用方法

1. 双击 `start.bat`，或执行 `.\.venv\Scripts\python.exe app.py`。
2. 选择源 `.xlsx` 文件和输出目录。
3. 选择金额口径，默认“销售金额(元)”，可改为“下单金额(元)”。
4. 点击“生成全部学校账单”。每次生成独立时间戳目录，不覆盖已有文件。
5. 查看每校四个 sheet，同时检查 `待核对记录.csv` 和 `运行报告.json`。
   也可点击程序底部“查看核对报告”，或双击输出目录的 `核对报告.html`，在浏览器离线查看金额、学校文件和可搜索的异常记录。异常位置使用源 Excel 工作表名称和左侧行号（包含表头），可按提示用 Ctrl+G 定位。
6. 如有待核对行，在源账单副本中修正客户名、地址关键词后重新生成。分类总计只包含已分类记录。

源表第一行必须包含唯一表头：客户名、收货地址、配送日期、选定金额列。读取其他原始列并保留；选定日期和金额会标准化。支持 Excel 日期和 yyyy-mm-dd、yyyy/mm/dd、yyyy.mm.dd 文本。仅支持 xlsx。

老师关键词：教师、成人、职工、老师。学生关键词：幼儿、学生。匹配整个收货地址文本；同时命中两类或均未命中为待核对。空客户名不生成学校文件，但写入异常清单。合计/总计且无日期、地址的行视为汇总行跳过。原始公式读取 Excel 已保存的缓存值；缓存缺失的金额会报错，需先用 Excel/WPS 重算并保存。

分类不使用客户名。匹配地址时排除机构名称中的“幼儿园”，避免“某幼儿园（成人）”误判为两类冲突；独立的“幼儿”备注仍归学生。

输出文件名采用实际最早/最晚配送日期（含年份），并增加编号避免非法字符清洗后重名。不是固定自然月起止日期。全部明细保留原序号和行顺序；总计表日期升序，底部有 SUM 公式。无分类数据时老师/学生明细仍保留表头。

## 常见问题

- 缺少表头：确认数据位于第一个 sheet，表头在第一行，名称与界面所选金额列一致。
- 金额或日期无效：按错误提示定位源行，修正副本后重新运行。
- PermissionError：关闭占用输出文件的 Excel，或选择有写入权限的文件夹。
- 公式暂时为空：openpyxl 不计算公式，Excel/WPS 打开后重算；精确核对金额见运行报告。
- `.xls` 文件：先另存为 `.xlsx`。
